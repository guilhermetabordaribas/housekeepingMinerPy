housekeepingMinerPy
===================

**housekeepingMiner** is a Python package to mine Housekeeping genes in RNA-Seq datasets. It improves normalization and data harmonization and mitigates overfitting in machine learning by avoiding data leakage.

visit the documentation: [https://housekeepingminerpy.readthedocs.io/en/latest/](https://housekeepingminerpy.readthedocs.io/en/latest/)
